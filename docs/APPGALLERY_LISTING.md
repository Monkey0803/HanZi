# HanZi 应用市场素材草案

## 基础信息

- 应用名称：HanZi · 汉字书写
- 分类：教育
- 建议年龄分级：3+
- 版本：1.0.0（versionCode 1000000）
- 一句话简介：离线学习小学语文生字、笔顺、描红与复习。

## 详细描述

HanZi 面向小学阶段的汉字学习场景，提供课本生字浏览、拼音与组词、原生笔顺动画、逐笔描红、单元复习和错题复习。课程、笔顺与学习记录均保存在本地，无广告、无账号、无网络依赖。应用支持手机、平板和 2in1 的响应式布局，并提供深色模式、主题色、每日目标、笔顺速度、拼音显示和语音朗读设置。
